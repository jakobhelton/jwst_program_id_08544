# JWST Program ID 8544

This repository contains the data products, reduction pipelines, and analysis tools that were developed to interpret the rest-frame optical spectrum of JADES-GS-z14-0, which is one of the most distant galaxies currently known, at a redshift beyond 14. These data include ultra-deep (~51 hours of integration time), low-resolution, mid-infrared spectroscopy of JADES-GS-z14-0 from JWST/MIRI as acquired by JWST Cycle 4 Program #8544 (with Principal Investigator, or PI, Jakob M. Helton). These observations were obtained by JWST/MIRI's Low Resolution Spectrometer (LRS) on 15-22 November 2025 and 1-2 January 2026.
